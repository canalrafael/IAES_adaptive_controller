1. CONTEXT & RESEARCH GOAL
--------------------------------------------------------------------------------
This experiment validates the core research hypothesis of the paper:

  "Microarchitectural contention (memory bandwidth saturation) injected during
   the profiling phase of the Autodidactic Neurosurgeon (ANS) muLinUCB controller
   causes it to choose a suboptimal split point (k^a != k^0), resulting in a
   persistent latency increase that is larger than the direct contention effect
   itself."

System Under Test:
- Split Inference pipeline: partitioned ResNet-18 (23 split points) across
  edge and server.
- Controller: muLinUCB (Autodidactic Neurosurgeon, WWW 2021) contextual bandit.
- Edge: Raspberry Pi 4 (ARM64).
- Server: PC running Windows 11 (PyTorch CUDA/CPU).

--------------------------------------------------------------------------------
2. SETUP & ACTIONS PERFORMED
--------------------------------------------------------------------------------
1. Flashed Raspberry Pi OS (64-bit) onto SD card using Raspberry Pi Imager.
2. Network connection: Raspberry Pi connected via Ethernet to router (IP: 192.168.1.222).
   Host PC connected to the same LAN (IP: 192.168.1.19).
3. Cloned repository onto the Pi:
   git clone https://github.com/canalrafael/IAES_adaptive_controller.git
4. Created and activated Python virtual environment:
   python3 -m venv venv
   source venv/bin/activate
5. Fixed dependencies and code:
   - Updated `split_inference/requirements_pi.txt`: adjusted PyTorch dependency 
     for ARM64 Debian/piwheels.
   - Fixed `split_inference/client.py`: added guard against ZeroDivisionError 
     when network emulation is disabled (bandwidth = 0.0) in hardware mode.
6. Synchronized repository changes via git (`git stash`, `git pull`).
7. Started Server on PC:
   python -m split_inference.run_hardware_server --port 5005
8. Executed Go/No-Go hardware validation experiment from the Raspberry Pi:
   python -m split_inference.run_gonogo_hardware --host 192.168.1.19 --port 5005 --workers 4

4. GO/NO-GO VERDICT
--------------------------------------------------------------------------------
Criteria:
1. Decision manipulated (k^a != k^0) > 50%:
   -> RESULT: 100.0% [PASSED]
2. Persistent post-attack cost (Delta_ctrl > 0):
   -> RESULT: +114.95 ms [PASSED]

OVERALL VERDICT: [GO] - RESEARCH HYPOTHESIS CONFIRMED
The muLinUCB controller was successfully manipulated in 100% of trials.
The control-induced amplification damage (+114.95 ms) is 2.4x larger than the
direct physical contention slowdown (+47.74 ms). This proves that applying
transient microarchitectural contention during learning causes persistent,
amplified system degradation.
